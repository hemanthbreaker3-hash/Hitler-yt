# Monetag Service Worker on Vercel

The supplied `sw.js` is served at `https://YOUR-DOMAIN/sw.js` by the Vercel
serverless handler before MongoDB initialization. This makes the exact worker
file available at the required website-root URL.

Supplied Monetag configuration:
- Domain: `3nbf4.com`
- Zone ID: `12276863`

After deploying, verify that `https://YOUR-DOMAIN/sw.js` returns HTTP 200 and
contains the supplied worker code. Use Monetag's dashboard Installation Check.

Important: Monetag's publisher instructions require the corresponding ad tag
from the Monetag dashboard in the page `<head>`; Push Notifications and MultiTag
also require this root `sw.js` file. The uploaded file contains the worker only,
not the ad-tag snippet. I have not invented a tag because Monetag says to copy the
exact code generated for the zone. Add that exact dashboard snippet to the site's
`<head>` if it is not already installed.

The worker imports Monetag's remote script from `https://3nbf4.com`.
Keep the supplied domain and zone ID unchanged unless Monetag provides replacements.


## Ad placement behavior
The site may place configured AdSense display units at randomized positions between poster cards. Set `ADSENSE_AD_SLOT` in Vercel to the numeric slot ID of a responsive display ad unit created in the AdSense account. The existing Monetag service worker remains available at `/sw.js`; the Monetag page tag is not included in this archive, so copy the exact tag generated by the Monetag dashboard before enabling additional Monetag on-page formats.

Ads are not opened by ordinary page taps, and the site does not hijack buttons/links, simulate clicks, or force pop-unders. Use only formats and placements permitted by the ad network policies.

## Telegram bot ad management (added)

The bot owner or an ID listed in `ADMINS` can manage ad tags directly in Telegram:

- `/adsense` — upload/replace an official AdSense `.txt`, `.html`, or `.js` tag file, enable/disable it, or remove it.
- `/monetag` — upload/replace an official Monetag tag file, enable/disable it, or remove it.

Uploads are limited to 64 KB and stored in the shared MongoDB `site_settings` document with `_id: "ad_config"`. A newly uploaded tag is disabled until an admin explicitly enables it. The Python website renderer and Vercel serverless renderer read the same settings document, so changes take effect without a bot or website restart. The Vercel `MONGODB_URI` and `DATABASE_NAME` must point to the same database used by the bot.

Only upload official provider ad tags from your own publisher dashboard. Do not upload account passwords, login cookies, or private API credentials. Ads are rendered in clearly marked placements; normal page taps and download buttons are not intercepted and no forced-click/pop-under behavior is added.

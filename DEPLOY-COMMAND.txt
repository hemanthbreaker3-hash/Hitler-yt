HITLER YT — SINGLE VPS DEPLOYMENT

1) Copy/paste the contents of deploy-one-command.sh into your VPS terminal,
   OR run it from the cloned project directory after obtaining the ZIP.
2) It asks for API_ID, API_HASH, OWNER_ID, optional admin/channel IDs,
   optional TMDB_API_KEY, BOT_TOKEN and MONGODB_URI. Secret inputs are hidden.
3) It clones to ~/animovieszoneflix, generates a strong ADMIN_PANEL_TOKEN if needed,
   writes a private .env file, and runs deploy.vps.

The admin dashboard is available at /panel. For first login, use username `admin`
and the ADMIN_PANEL_TOKEN from the private backend .env file. After the bot starts,
set your own browser login directly in Telegram using `/username new_username`
and `/password a_strong_password` (minimum 10 characters). The bot deletes each
credential command message when Telegram permits it; use these commands in a
private chat with the bot. The password is stored as a salted hash in MongoDB.


No script can guarantee 100% success: GitHub access, VPS DNS/network, Atlas IP
allowlist, credentials, Telegram bot permissions and public BASE_URL are external
requirements. The script performs preflight validation and prints logs on failure.

For the automatic public tunnel, export your ngrok auth token before running the deployment script:

   export NGROK_AUTHTOKEN=YOUR_NGROK_AUTH_TOKEN
   ./deploy.vps

The deployment script persists this value into .env for the Docker application. You can also set NGROK_AUTHTOKEN in .env directly.
The web app starts ngrok internally and saves its generated HTTPS URL in MongoDB and .env.
Watch startup and URL synchronization with:

  docker compose logs -f web

The tunnel is managed by the web application and restarts with the container.
